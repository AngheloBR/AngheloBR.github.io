# anghelobr.github.io

Personal site of Jaren Bailon (@AngheloBR): Linux server hardening service + public labs and notes.
Built by GitHub Pages with Jekyll (no build step on your side; push and it deploys).

## Run locally

```
sudo apt install ruby-full build-essential zlib1g-dev   # once
bundle config set --local path vendor/bundle             # once
bundle install                                           # once, same gems as GitHub Pages
bundle exec jekyll serve                                 # http://127.0.0.1:4000
```

## Structure

```
index.html              Home (EN/ES, dark/light). Lab cards are generated from _labs/.
_labs/*.md              One file per lab (Markdown + front matter). URL: /<file-name>.html
_layouts/base.html      <html>, head include, page scripts.
_layouts/lab.html       Lab page: header, content, prev/next (by `order`).
_includes/head.html     Meta, Open Graph, theme/lang bootstrap, fonts, CSS.
_includes/nav-lab.html, footer-lab.html
404.html, sitemap.xml   Generated by Jekyll. robots.txt is static.
assets/site.css         Tokens (colors, type), reset, nav, buttons, footer.
assets/home.css         Home sections and the 3D scene shell.
assets/lab.css          Article styles: header, content, code, callouts, side index, prev/next.
assets/site.js          Theme toggle, mobile menu, copy buttons, scroll reveal.
assets/home.js          Spanish copy + language toggle, lab filters.
assets/lab.js           Builds the sticky "On this page" index from h2 headings.
assets/scene.js         The perimeter demo (three.js, loaded on demand from assets/vendor/).
assets/fonts/           Self-hosted woff2 (OFL, see LICENSE.txt).
og.png                  Social preview; regenerate by screenshotting _og.html at 1200×630.
_archive/               Old pages, not published (Jekyll skips _folders).
```

## Adding a lab

Create `_labs/lab-005-something.md`:

~~~markdown
---
title: "Lab 005 · Something — Jaren Bailon"
description: "One sentence, used for search results and link previews."
order: 6                      # position in the prev/next chain
nav_title: "Lab 005 · Something"
crumb: "Lab 005"
badge: "LAB 005 · Security"
heading: '<span class="accent">Something</span> on Debian'
intro: "Intro paragraph under the title (HTML allowed)."
card_order: 2                 # position on the home page
card_flagship: false
card_type: "Lab 005"
card_is_lab: true
card_filters: "debian lab security"   # which filter chips show it
card_tags: ["debian", "security"]
card_title: "Something"
card_desc: "English card text."
card_title_es: "Algo"
card_desc_es: "Texto de la tarjeta en español."
---
~~~
